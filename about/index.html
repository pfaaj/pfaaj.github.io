About

I’m a senior software engineer and technical lead at Mercedes-Benz Tech Innovation, where I architect and build microservice-based systems on Kubernetes. I have a real soft spot for distributed systems, performance optimization and the responsible use of AI.

Before joining Mercedes-Benz Tech Innovation, I did a PhD in computer science on wireless ad-hoc networks, which I finished magna cum laude.

AI in my work

Over the last few years, AI has moved from a curiosity to the center of how I build software. A few things I’ve been working on:

  • Agentic development workflows: using coding agents for code generation backed by quality and security gates, data analysis, data summarization and PR reviews.
  • Local, open-weight models: running models on-device as code reviewers or decision models.
  • Human-in-the-loop AI for car engineering: regulation compliance validation, building semantic layers backed by knowledge graphs, and smarter search for multiple use cases within Mercedes-Benz.
